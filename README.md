# Greysheep's Hub

个人主页，包含多个实用小工具。

## 功能

- **实时时钟** — 显示当前时间、日期和星期
- **天气卡片** — 基于 Open-Meteo API，自动获取当地天气（需允许浏览器定位）
- **每日一句** — 中英文随机励志名言
- **倒计时** — 自定义事件名称和目标日期，数据保存在本地
- **番茄钟** — 支持专注/短休/长休模式，带进度条

## 使用

直接用浏览器打开 `index.html` 即可，无需任何构建工具或服务器。

## 技术

- 纯 HTML + CSS + JavaScript，无任何依赖
- Glassmorphism 毛玻璃设计风格
- 响应式布局，适配桌面和移动端
